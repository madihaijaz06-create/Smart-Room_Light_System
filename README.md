# Smart-Room_Light_System
IoT project using Arduino, LDR and PIR motion sensor for automatic lighting and security alerts.
## Wokwi Simulation

[Click here to run the Smart Room-Light System](https://wokwi.com/projects/478863136083283969)

## Components
- Arduino Uno
- LDR (photoresistor) sensor
- PIR motion sensor
- LED
- Buzzer

## Features
- Automatic lighting based on sensor input
- Motion detection
- Security alert using a buzzer
